# Project C.A.R.L. // Roblox Ragdoll & Anatomy Physics Engine

Полная игра и физическая песочница рэгдолла для **Roblox Studio**, вдохновленная культовым проектом **Project C.A.R.L.** (*Clinical Assistant for Research & Learning*) и песочницами *Ragdoll Engine* / *People Playground*.

Включает проработанный **R15 риг манекена со скелетом и внутренними органами**, систему рэгдолла игрока и манекена на **клавишу [F]**, баллистическое пробивание органов, реалистичную физику крови и полигон для испытаний (30-ступенчатая лестница для трюков, горка, батут и вращающийся барьер).

---

## 🎮 Быстрый старт (Как открыть игру)

В репозитории уже собран **готовый файл плейса**: `Ragdoll_Game.rbxlx`.

### Вариант 1: Напрямую в Roblox Studio (Рекомендуется)
1. Скачайте репозиторий или файл `Ragdoll_Game.rbxlx`.
2. Откройте **Roblox Studio**.
3. Выберите в верхнем меню **File** $\rightarrow$ **Open from File...** и выберите `Ragdoll_Game.rbxlx`.
4. Нажмите **Play (F5)** и наслаждайтесь!

### Вариант 2: Через Rojo (для разработчиков)
Репозиторий содержит файл конфигурации `default.project.json` и исходный код в папке `src/`:
```bash
rojo serve
```
Или собрать новый `.rbxlx` скриптом:
```bash
python3 tools/build_place.py
```

## ⌨️ Управление в игре

| Клавиша / Действие | Назначение |
|---|---|
| **[F]** | **Включить / Выключить свой рэгдолл** (падаешь тряпичной куклой, повторное нажатие плавно поднимает на ноги) |
| **[E]** *(рядом с манекеном)* | **Переключить рэгдолл манекена** (уронить / поднять манекен) |
| **[R]** *(рядом с манекеном)* | **Восстановить / Оживить манекен** (сброс позиции и лечение до 100 HP) |
| **[X]** | **Режим рентгена (X-Ray)** — делает кожу манекена прозрачной, открывая обзор на мозг, сердце и позвоночник |
| **Слот [1]** | **Пистолет 9mm** — точная баллистика, лазерные трассеры, точечные повреждения органов |
| **Слот [2]** | **Дробовик 12G** — 8 дробинок, колоссальный импульс отдачи (сбивает с ног и отбрасывает) |
| **Слот [3]** | **Толкатель (Push Hands)** — толчок руками в упор, моментально отправляет цель в рэгдолл |
| **Слот [4]** | **Жезл Рэгдолла** — дистанционное переключение рэгдолла по клику мыши |

## 🧬 Анатомическая система (Project C.A.R.L. Anatomy)

Внутри манекена **C.A.R.L.** встроены отдельные анатомические хитбоксы органов:

1. **Мозг (`Brain`)** — расположен в голове.
   - Попадание: критический урон 100 HP, моментальная гибель и падение в рэгдолл.
   - Уведомление на экране: `🎯 HEADSHOT: МОЗГ УНИЧТОЖЕН!`
2. **Сердце (`Heart`)** — расположено в верхней части торса.
   - Попадание: тяжелый урон 80 HP, артериальный фонтан крови (`ParticleEmitter`) и коллапс.
   - Уведомление: `❤️ ПРОБИТИЕ СЕРДЦА: АРТЕРИАЛЬНОЕ КРОВОТЕЧЕНИЕ!`
3. **Позвоночник (`Spine`)** — вертикальный столб вдоль торса.
   - Попадание: перелом позвоночника, мгновенный паралич и падение в рэгдолл.
   - Уведомление: `🦴 ПОЗВОНОЧНИК СЛОМАН: ПАРАЛИЧ!`
4. **Легкие (`LeftLung`, `RightLung`)** — дыхательные органы.
   - Попадание: урон 45 HP, сильный импульс ранения.
5. **Брюшная полость (`Stomach`)** — в нижнем торсе.
   - Попадание: урон 35 HP.

## 🩸 Физика крови (Blood Engine)

- **Брызги и частицы:** капли крови разлетаются в стороны в зависимости от угла попадания пули.
- **Пятна на стенах и полу:** Raycast определяет нормаль ближайших поверхностей и создает реалистичные потеки и декали.
- **Лужи крови:** под лежащими телами динамически увеличиваются лужи крови (`TweenService`).
- **Артериальные струи:** при ранении сердца активируется пульсирующая струя под давлением.

## 🎪 Полигон для испытаний (Testing Lab Map)

Карта специально спроектирована для максимального веселья с рэгдолл-физикой:

1. **Лестница для трюков (Stunt Stairs):**
   - 30 ступеней в высоту с наблюдательной площадкой наверху.
   - На вершине стоит тестовый манекен — толкните его или нажмите **[F]** сами, чтобы скатиться кубарем по всем 30 ступеням!
2. **Крутая горка (Mega Slide):**
   - Ледяная поверхность с минимальным трением, заканчивающаяся трамплином-кикером.
3. **Супер-батут (Launchpad):**
   - Подбрасывает рэгдоллы на 95 стадов в воздух.
4. **Кинетическое бревно (Kinetic Spinner):**
   - Вращающийся неоновый барьер на круглой арене, сбивающий с ног любого подошедшего.
5. **Стрелковая позиция:**
   - Пьедестал с манекеном C.A.R.L., разметкой дистанции и стрелковой стойкой.

```
    │   ├── RagdollController.client.luau # Обработка клавиш [F] и [X], слежение камеры
    │   └── RagdollHud.client.luau      # Научно-лабораторный интерфейс, бейджи и боевые тосты

        ├── Shotgun/                    # Дробовик 12G
        ├── PushTool/                   # Руки-толкатель
        └── RagdollWand/                # Жезл рэгдолла
```

## 🛠️ Совместимость
- **Roblox Studio:** Любая актуальная версия (2024–2026+).
- **Тип рига:** **R15** (полная анатомия из 15 частей) с обратной совместимостью с R6.
- **Поддержка платформ:** ПК (мышь + клавиатура) и мобильные устройства (сенсорные кнопки на HUD).
